# Edit Fee Waiver Reason

> **Module:** ssi_school_fee_waiver\
> **Model:** `school_fee_waiver_reason`\
> **Menu:** School > Configuration > Fee Waiver > Fee Waiver Reasons\
> **Actor:** user in group `Fee Waiver Reason`\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** A Fee Waiver Reason already exists.
- **Access:** User is in group `Fee Waiver Reason`.

## Flow

1. Open the **School > Configuration > Fee Waiver > Fee Waiver Reasons** menu.
2. Find and open the record to edit.
3. Change the required fields, for example **Name**, **Code**, or **Sequence**.
4. Click **Save**.

## Post-Condition

- The record is updated with the new values.
